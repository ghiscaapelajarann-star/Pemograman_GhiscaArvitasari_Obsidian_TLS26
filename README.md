# Pemograman_Ghisca Arvitasari_TLS26

## Identitas

**Nama Lengkap:** Ghisca Arvitasari

**Kelompok:** Obsidian

## Deskripsi Repository

Repository ini berisi hasil pengerjaan tantangan fase pertama dan fase kedua.

Pada **Fase 1**, repository berisi satu file PDF yang memuat hasil logika penyelesaian masalah dalam bentuk flowchart.

Pada **Fase 2**, repository berisi dua file program C++ yang merupakan implementasi dari solusi kedua problem berdasarkan logika penyelesaian masalah yang telah dibuat pada Fase 1.

## Isi Repository

* `FLOWCHART.pdf` : Dokumen hasil pengerjaan tantangan Fase 1.
* `Problem 1.cpp` : Implementasi solusi Problem 1 menggunakan bahasa C++.
* `Problem 2.cpp` : Implementasi solusi Problem 2 menggunakan bahasa C++.
